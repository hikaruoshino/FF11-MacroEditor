[5. What this tool does (please understand the risk before using it)]
- This tool is not officially approved. It reads game files and creates edited files.
- It reads the macro files (mcr*.dat and mcr*.ttl) in the character's folder and the equipment set names (es*.dat).
- The "game slot" feature reads the files of the file slots (A-D) on the character selection screen, decrypts them and extracts the macros inside.
  For output, it re-encrypts the slot file with the replaced macros into the same format. To decrypt, it reads part (a table) of PlayOnline's polcore.dll.
- It does not touch the running game program or its memory.
- This tool does not write into the game's folder. The edited result is output to a separate folder. Overwriting the game's folder is your own operation.
